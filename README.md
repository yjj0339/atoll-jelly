# 环礁果冻 · Atoll Jelly

**材质研究 No.07 · MALDIVES** — 一块方形切出的马尔代夫青绿色果冻泻湖。

原生 **WebGPU + WGSL**，模拟为纯 JavaScript，单个自包含 HTML，**零外部请求**。

> 六座高脚水上屋，一架来来去去的水上飞机，还有在下方果冻里滑行的鹞鲼。

## 在线体验

GitHub Pages：<https://yjj0339.github.io/atoll-jelly/>

需要支持 WebGPU 的浏览器（桌面 Chrome / Edge 113+，Android Chrome 121+，macOS Sequoia / iOS 26+ Safari）。不支持时显示降级提示卡。

## 场景

- 5.2² 果冻方块，海平面 1.3；白沙泻湖 + 前角斜降的深「蓝洞」。
- 八座摆动珊瑚丘（脑珊瑚 / 枝状 / 海扇，六色）。
- 左后沙岛：8 棵 16 叶椰子树（羽状复叶 + 枯叶裙 + 椰果）、软糖灌木、茅草大亭、遮阳伞躺椅。
- 细桩木板栈桥斜穿泻湖，灯柱；五座交替水上屋 + 尽头大屋（泳池、铜梯、玻璃推拉门、条纹茅草顶）。
- 浮台水上飞机（双发浮筒、三叶螺旋桨顶点旋转）+ 架桩步道。
- 切面糖果地层：沙 / 贝壳 / 焦糖 / 巧克力，外罩清透果冻壁。

## 水体与生态

- 168² 交错网格 120 Hz 线性浅水方程，波速 √(g·水深)，表面张力、阻尼、倾斜晃荡。
- 手指搅动、漂浮物排水、水花坑 + 气泡、泡沫花边、焦散、光柱、折射、Beer-Lambert 口味吸收。
- 42 条四色 boids 鱼 + 3 只斑点鹞鲼（顶点着色器摆尾 / 扇翅），始终在水里、会被惊散。
- 喂鱼 16 颗先浮后沉被吃掉计数；糖果游泳圈平浮、可抓扔、会被飞机推开。
- 水上飞机完整每日循环：等待→掉头→滑行→起飞→爬升→3.1 高度巡航→进近→接水→滑跑→转向→回浮台。

## 果冻 Q 弹

整块果冻为欠阻尼弹簧体：squash & stretch + 剪切 + 行进波纹 + 局部按压凹陷。
搅动 / 水花 / 接水 / 扔圈 / 倾斜都会触发回弹；「Q 弹」滑块实时调节。

## 玩法

搅动泻湖。嘻嘻鱼。挥手送水上飞机起飞。

- 拖动环绕 · 滚轮 / 双指缩放
- 按住水面划动搅起波浪
- 抓住游泳圈甩出去
- 在空中快速挥一下，送水上飞机起飞
- 移动端底部抽屉控制台
